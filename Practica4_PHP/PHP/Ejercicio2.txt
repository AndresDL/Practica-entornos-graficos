
Indicar si los siguientes codigos son equivalentes:

A- <?php                
    $i = 1;
    while ($i <= 10) { 
        print $i++;
    }
    ?>

    <?php
    $i = 1;
    while ($i <= 10):
        print $i;
        $i++;
        endwhile;
    ?>

    <?php 
    $i = 0; 
    do { 
        print ++$i; 
        } while ($i<10);
    ?>

Los 3 segmentos de codigo son equivalentes. Se llega siempre a la misma salida 12345678910 utilizando distinta sintaxis para definir el bucle
while. La unica gran diferencia es que en el caso 3 se inicia $i en 0 en vez de 1 y se itera hasta que $i < 10 en vez de <=.


B- 
    <?php
        for ($i = 1; $i <= 10; $i++) { 
            print $i;
        }
    ?>

    <?php
        for ($i = 1; $i <= 10; print $i, $i++) ;
    ?>

    <?php
        for ($i = 1; ;$i++) { 
            if ($i > 10) { 
                break; 
            } print $i; 
        }
    ?>

    <?php 
        $i = 1; 
        for (;;) { 
            if ($i > 10) { 
                break; 
            } 
            print $i; $i++; 
        } 
    ?>

Los 4 segmentos de codigo son equivalentes, en todos se llega a la misma visualización de 12345678910. En los ultimos 2 en vez de validar dentro
del for si la condición para terminar el for se cumple, directamente se rompe el for mediante un break y validar con un if. 


C- 
    <?php
        …
        …
        if ($i == 0) { 
            print "i equals 0"; 
        } elseif ($i == 1) { 
            print "i equals 1"; 
        } elseif ($i == 2) { 
            print "i equals 2"; 
        }
    ?>

    <?php
        …
        …
        switch ($i) {
            case 0: 
                print "i equals 0"; 
                break; 
            case 1: 
                print "i equals 1"; 
                break; 
            case 2: 
                print "i equals 2"; 
                break; 
        }
    ?>

Ambos casos son equivalentes, si se define una variable $i = 1, 2 , 0 se obtiene las salidas "i equals 1", "i equals 2", "i equals 0" 
respectivamente. La diferencia entre ambos es usar if y elseif encadenados para simular el comportamiento de la sentencia switch que funciona
por distintos casos.
